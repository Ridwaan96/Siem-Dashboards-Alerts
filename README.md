# Siem-Dashboards-Alerts
In this lab we create dashboard panels on splunk and also alerts and watch the alerts trigger. 
We create a manual log with different failed logs with different time charts. using spl query, we filter these logs
and create dashboard panels viewing all different logs in a vitualized manner to make it easier to read.
we create these dashboards according to 
- failed logs
- ip address
- time charts

we make a line chart, bar chart and also a pie chart
